# Persona Motion — 개인용 힉스필드 영상 제작 도구

API 키 없이, 내 PC에서 실행하는 제작 페이지와 로그인 세션을 유지하는 Playwright 브라우저입니다. Higgsfield의 비공식 브라우저 연동 도구입니다.

## 설치 및 실행

Windows / macOS / Linux PC에 **Node.js 20 이상**을 설치한 후 이 폴더에서 터미널을 엽니다.

```sh
npm ci
npm run setup:browser
npm start
```

브라우저에서 **http://127.0.0.1:4317** 을 엽니다. 서버와 자동화 브라우저는 같은 PC에서 실행해야 합니다. Linux에서 Chromium이 공유 라이브러리 오류를 내면 Playwright 공식 설치 안내에 따라 시스템 의존성을 설치하세요.

## 사용 순서

1. 제작 페이지의 **힉스필드 연결**을 누릅니다. 별도의 Chromium 창이 열립니다.
2. 그 창에서 직접 힉스필드에 로그인합니다. 평소 쓰는 Chrome 로그인과는 별개의 전용 프로필입니다. 인증이나 추가 확인이 나오면 직접 완료하세요.
3. 힉스필드의 이미지→영상 제작 화면으로 이동합니다. 모델, 영상 길이, 화면 비율을 선택합니다.
4. 제작 페이지에서 인물 이미지와 장면 설명을 선택하고 **이미지 + 프롬프트 자동 입력**을 누릅니다.
5. 힉스필드 창에서 이미지 업로드가 완료됐는지, 모델 설정과 예상 비용이 맞는지 확인합니다.
6. 제작 페이지의 **힉스필드에서 생성 요청**을 누르면 브라우저의 생성 버튼을 한 번 클릭합니다. 크레딧이 사용될 수 있습니다. 버튼 클릭 성공이 생성 성공을 뜻하지는 않습니다.
7. 제작 페이지의 **결과 영상 검색**을 누릅니다. 열린 힉스필드 결과 화면의 영상 후보를 찾습니다. 후보의 **가져와서 확인**을 누르면 영상이 로컬로 저장되고 제작 페이지에서 바로 재생·다운로드할 수 있습니다. 후보가 방금 생성한 영상인지는 재생해 확인하세요.
8. 직접 가져오기가 지원되지 않는 blob/HLS 영상이나 접근이 거부된 파일은 힉스필드의 Download를 사용하세요. 해당 브라우저의 다운로드도 수집되며 페이지에 표시됩니다.

터미널을 종료하면 도구가 중지됩니다. 다음에 `npm start`로 실행하면 로그인 세션을 재사용합니다. 만료되거나 재인증이 필요하면 다시 로그인하세요.

## 자동화 범위 및 검증 상태

- 구현: 브라우저 시작, 전용 프로필 보존, 이미지 자동 업로드, 프롬프트 자동 입력, 생성 버튼 단일 클릭, 현재 화면의 결과 영상 검색, HTTPS MP4/WebM/MOV 파일 가져오기(150MB 이하), 페이지 내 플레이어·다운로드, 브라우저 다운로드 수집.
- 수동: 첫 로그인, 제작 화면 및 모델 선택, 추가 인증, 결과 화면 열기, 영상 후보 선택. 지원하는 영상은 이후 확인과 다운로드를 제작 페이지에서 진행할 수 있습니다.
- 현재 실제 로그인된 Higgsfield 화면을 확인하지 못했습니다. 기본 선택자는 보편적인 파일 입력/텍스트 입력/생성 버튼을 탐색합니다. 실제 서비스에서는 **연결 설정 조정이 필요할 수 있습니다**. 실제 영상 생성 성공을 검증한 상태가 아닙니다.
- 자동화 탐색이 애매하면 임의의 항목을 선택하지 않고 중단합니다. 생성 실패/타임아웃은 자동으로 재시도하지 않습니다. 힉스필드에서 작업이 이미 만들어졌는지 먼저 확인하세요.
- 로그인 차단이나 CAPTCHA를 우회하는 기능은 없습니다. 서비스가 자동화 브라우저 로그인을 허용하지 않으면 수동 제작을 사용해야 합니다.

## 화면 변경 시 연결 설정

페이지 하단 **연결 설정 및 작업 기록**에서 실제 힉스필드 영상 제작 주소와 CSS 선택자를 저장할 수 있습니다. 저장한 시작 주소는 다음 브라우저 시작에 적용됩니다. 이미 열린 창은 직접 해당 주소로 이동하세요.

| 설정 | 기본 탐색 |
| --- | --- |
| 이미지 업로드 | `input[type="file"][accept*="image"]` |
| 프롬프트 | 표시 중인 `textarea` 또는 `[contenteditable="true"]` |
| 생성 버튼 | Generate / Create / 생성 / 영상 생성 이름의 버튼 |
| 결과 영상 | `main video` (필요시 실제 결과 영상 요소 선택자로 조정) |

항목이 여러 개이거나 하나도 없으면 오류가 표시됩니다. 개발자 도구로 실제 요소의 안정적인 CSS 선택자를 확인해 입력하세요. 설정의 예시 선택자는 실제 힉스필드 DOM에 대해 검증된 값이 아닙니다.

## 로컬 데이터

- `.local/browser-profile/`: 로그인 쿠키 등 민감한 브라우저 프로필. 공유하거나 Git에 올리지 마세요.
- `.local/settings.json`: 시작 주소와 선택자. 비밀번호와 API 키는 수집하지 않습니다.
- `.local/downloads/`: 영상 등 다운로드 결과.
- `.local/uploads/`: 업로드 작업 동안만 임시 저장되며 성공/실패 후 삭제합니다. 비정상 강제 종료 시 남은 파일은 직접 삭제할 수 있습니다.

서버는 `127.0.0.1`에만 바인딩하며 다른 사이트에서 온 요청을 차단합니다. 공개 서버에 배포하거나 포트포워딩하지 마세요. 프로필을 초기화하려면 앱 종료 후 `.local/browser-profile/`을 삭제하세요.

## 검사

```sh
npm test
```

테스트는 로컬 요청 제한, 이미지 형식 검사 및 임시 파일 정리, 생성 클릭 실패 후 중복 요청 방지를 검증합니다. 계정 로그인이나 유료 생성 작업은 테스트에서 수행하지 않습니다.

## 실행 및 검증 기록

현재 Codex 클라우드 작업 환경에서 `npm ci`, Chromium 설치, 서버 실행을 완료했습니다. 사용자 PC에 설치되거나 실행된 것은 아닙니다. 이 클라우드 환경에서는 로그인할 데스크톱 조작 도구가 제공되지 않아 실제 계정 연결은 미검증입니다. 결과 후보는 현재 열린 화면의 영상 요소를 검색하며 서비스의 작업 ID와 연결된 완료 판정 또는 자동 다운로드 예약 기능은 아닙니다.

로컬 샘플 MP4로 웹 플레이어 재생, 상태 갱신 중 플레이어 유지, 파일 다운로드, 부분 전송(HTTP Range)을 확인했습니다. 실제 Higgsfield 결과 가져오기는 계정 로그인 후 별도 확인이 필요합니다.
